CORRECTIF GITHUB PAGES — LEVEL UP ACADEMY

Adresse cible : https://bym-level-up-academy.github.io/levelupacademy/

Cette archive contient uniquement les fichiers a remplacer et .nojekyll.
Les chemins des CSS, scripts, images, polices et liens internes commencent maintenant par /levelupacademy/.

1. Extraire completement cette archive.
2. Copier son contenu dans le dossier local du depot, en fusionnant les dossiers et remplacant les fichiers existants. Ne pas supprimer les autres fichiers du depot : les images non modifiees ne sont pas incluses.
3. Commit puis push vers main. Ou televerser le contenu extrait dans le depot GitHub via Add file > Upload files, puis Commit changes. Ne pas televerser seulement le ZIP.
4. Attendre la fin du deploiement Pages, puis recharger avec Ctrl+Maj+R.

La configuration GitHub Pages reste main / (root).
LIRE-MOI.txt et MANIFEST-SHA256.json remplacent les fichiers de documentation precedents.
Le panier reste une demonstration, sans commande ni paiement.
Les chemins ciblent precisement /levelupacademy/ ; ils devront etre adaptes si l'adresse du site change.
